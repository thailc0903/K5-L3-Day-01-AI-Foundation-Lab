## 3. Dự đoán và thực tế
1. Stress Test
Dự đoán: LLM đạt Accuracy khoảng 80–90%.
Thực tế: LLM đạt 100% trên 50 case khó.
Nguyên nhân:  đánh giá thấp khả năng hiểu ngữ cảnh và nhận diện Prompt Injection của LLM trên bộ dữ liệu này.
2. So sánh LLM và MiniLM
Dự đoán: LLM Zero-shot có chất lượng gần tương đương MiniLM + LogReg.
Thực tế: Trên SUB 40, MiniLM + LogReg đạt F1 = 0.889, LLM nhỏ đạt 0.952 và LLM lớn đạt 1.000.
Nguyên nhân: LLM tận dụng kiến thức tiền huấn luyện và hiểu ngữ cảnh tốt hơn dự kiến.
3. Deep Learning MLP
Dự đoán: MLP có F1 tương đương hoặc thấp hơn BoW + LogReg vì dễ overfitting.
Thực tế: MLP đạt F1 = 0.922, cao hơn LogReg (0.874).
Nguyên nhân: Lớp ẩn và ReLU giúp mô hình học quan hệ phi tuyến, cải thiện khả năng phân loại dù có dấu hiệu overfitting.
